Field-level crop water requirement and net irrigation maps in QGIS

"How much water will this field need this season?" is a question that comes up all the time in irrigation planning. I've released a new open-source QGIS plugin that answers it for many fields at once: FAO-56 Crop Water Requirement Mapper.

🌦️ Downloads NASA POWER climate data by itself (no API key) and computes daily ETo with the FAO-56 Penman-Monteith method
🌱 FAO-56 Table 11 and 12 stage lengths and crop coefficients were checked one by one against the printed publication
💧 Subtracts effective rainfall and computes the net irrigation requirement per dekad as in CROPWAT (or per day), in mm, m³, m³/da and m³/ha
🗺️ Styles the field layer by net irrigation and writes daily and dekad CSV files plus an HTML report with the method, data source and warnings
⚙️ A QGIS Processing tool: works in batch mode and in the Graphical Modeler; areas are ellipsoidal
✅ The calculation core is unit-tested against the FAO-56 worked examples; the plugin passed the QGIS security scan and the Qt6 compatibility check

This is an experimental release. NASA POWER is a coarse global dataset; support for local station data is coming in the next version. Feedback from colleagues working in irrigation, agricultural water management and GIS is very welcome.
